# 积分余额查询与排名端点计划

> 2026-08-19 · 分支 `feat/scoring-balances` · 状态：**已实现并验证**（后端 a8b1eaf + 前端 c3e5368，710 后端 / 229 前端测试全绿，浏览器 e2e 联动验证通过）

## 1. 背景与结论

积分管理面板（`/admin/scoring`）已能查流水 + 单条调分，但**没有任何端点能回答「所有玩家当前各有多少积分」**。唯一途径是翻某账号流水最后一条 `balance_after`，无聚合、无排名、无分页总览。

**结论**：新增 `GET /v1/scoring/admin/balances`（特权 JWT 余额排名榜），前端积分管理页加「玩家积分」tab 消费。`/me` 自查余额（`/me/scores`）**不在本计划内**（根 CLAUDE.md §7 另行跟踪，YAGNI）。

## 3. 端点设计

### GET /v1/scoring/admin/balances

| 项 | 设计 | 理由 |
|---|---|---|
| 鉴权 | **仅特权 JWT**（复用 `require_privileged_access`） | 与 admin/adjust、admin/players 同一通道；**admin ≠ service-token**（service-token 调用 → 401 `missing authorization`） |
| 归属锚 | **WebAccount**（`account_id`） | `balance_after` 本就按账号记账（R-5）；玩家改名/多 UUID 不产生余额分裂 |
| 行集 | 有 ≥1 绑定玩家的账号 | 未绑定玩家 credit/debit 本就 skip，无积分语义 |
| 余额 | `SUM(delta)` 聚合 | append-only 可审计重建（R-2），与最新 `balance_after` 天然一致 |
| 排序 | `balance DESC, account_id ASC` | 榜单语义 + 平分稳定序 |
| 参数 | `page`（≥1）、`limit`（默认 50，≤200） | 对齐 ledger 分页约定 |

**响应 schema**（金额 string，前端既有约定）：

```
ScoreBalancesPage {
  items: [{
    account_id: int
    display_name: str            // account.display_name，空回退玩家名主源
    player_names: [str]          // 同账号全部 current_name 去重
    balance: str                 // SUM(delta)，可负
    entries_count: int
    last_entry_at: datetime|null
  }]
  total: int; page: int; limit: int
}
```

**SQL（repo 层单查询）**：

```sql
SELECT a.id, a.display_name,
       array_agg(DISTINCT p.current_name)      AS player_names,
       COALESCE(SUM(l.delta), 0)               AS balance,
       COUNT(l.id)                             AS entries_count,
       MAX(l.created_at)                       AS last_entry_at
FROM users.web_accounts a
JOIN users.players p ON p.web_account_id = a.id
LEFT JOIN scoring.score_ledger l ON l.account_id = a.id
GROUP BY a.id, a.display_name
ORDER BY balance DESC, a.id
LIMIT :limit OFFSET :offset
-- total 另发一条 COUNT(DISTINCT a.id) FROM web_accounts a JOIN players p ...
```

## 4. 前端设计（ScoringAdmin.vue 加 tab）

```mermaid
flowchart LR
    A[/admin/scoring] --> T{el-tabs}
    T -->|积分流水| L[现有流水表 + 筛选]
    T -->|玩家积分| B[balances 排名表]
    B -->|调分成功后| R[两 tab 数据失效 → 重载当前页]
```

- 「玩家积分」tab 列：排名（`(page-1)*limit + i + 1`，mono）、账号（mono）、显示名、玩家名（`、` join）、余额（mono，负数 danger 色 tag）、流水笔数、最近变动；服务端分页（复用 `LIMIT_OPTIONS`）+ 刷新按钮。
- `api/scoring.ts` 加 `ScoreBalanceRow` / `ScoreBalancesPage` / `fetchBalgers → fetchBalances(params)`；金额 string。
- 调分成功后 balances 一并失效（下次切 tab 或刷新时重取；如当前在玩家积分 tab 则立即重载）。
