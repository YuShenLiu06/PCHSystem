## 〇、排序草案检验结论（5 处修正）

草案大方向正确（先去重、后拆分、契约最后、service 层出计划），但需修正：

| 2 | P1 动 SheetEditor、P4 才动 useSheetDetail——同端同测试套件被拆进两个 phase，中间态是新组件挂旧 composable | **C8+C10 提前进 P1**：前端一个 phase 全做完，落地即达红线 |
| 3 | P2 只做 in-file 瘦身：1710−600(C2)−90(C7)≈1010，**仍超 800 红线**，缺口没算 | P2 必须包含渲染层抽出（`sheet_render.py`，照 `construction_commands.py` 三分先例），主文件降到 ~700 |
